# Introdução
Disciplina eletiva ofertada no primeiro semestre de 2026 pelo professor Eduardo Corrêa. O curso é focado na linguagem de programação Python e terá duas avaliações. A primeira será uma prova de múltipla escolha e a segunda será a elaboração e apresentação de um trabalho envolvendo um modelo de Naive Bayes. 

# Estrutura do Curso
O curso pretende abordar três grandes tópicos: Programação Orientada à Objeto (POO); Introdução às Estruturas de Dados; e, Data Frames, Computação Vetorizada e outros temas. O principal tópico do curso será o primeiro, e ao longo do curso temas ligados a Inteligência Artificial (especificamente Processamento de Linguagem Natural) e Machine Learning serão vistos também, mas sem serem o grande foco.
